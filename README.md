# Basecamp

Outdoor educator platform (Phase 1).

Clean, app-like educator dashboard for managing documents, selective sharing with companies, availability, and work logs.

## Phase 1 features
- Homepage with Educator / Company signup
- Educator account creation
- Tabbed dashboard: Home, Documents, Share, Pay, Profile
- Document vault with common outdoor certs (SCRC, First Aid, Lifeguard, etc.)
- Invite acceptance + selective sharing
- Work logs (manual + simulated voice note)
- Profile (account, health, bank, availability calendar)
- Local persistence

Open `index.html` in a browser to try it.
